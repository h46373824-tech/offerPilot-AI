# OfferPilot AI v1.0.1

发布日期：2026-07-16

OfferPilot AI v1.0.1 是首个稳定公开版本，面向 2027 届校招场景，提供本地部署的企业与岗位发现、求职流程管理、数据分析和官方招聘来源同步能力。

## 核心能力

- 访客无需登录即可浏览企业、岗位、Dashboard 和官方投递入口。
- 注册用户可管理收藏、投递、面试、Offer、通知、简历与岗位提醒。
- 企业与岗位支持分页、搜索、筛选、排序以及核验状态展示。
- Dashboard 提供企业、学历、岗位、投递、面试、Offer、截止提醒和趋势分析。
- 本地调度器每天 05:00（Asia/Shanghai）检查到期的授权官方来源。
- Docker Compose 一次启动 Next.js、FastAPI、PostgreSQL 和 Redis。

## 数据范围

- 30 家 Demo 企业和 60 个 Demo 岗位，仅用于功能演示，均标记为 Demo。
- 发布基线包含截至 2026-07-16 核验的 14 家企业和 30 个正式招聘项目或岗位。
- 正式数据记录来源 URL、核验日期和状态；投递前仍应以企业官方页面为准。
- 本项目不承诺覆盖全网、所有企业或实时招聘状态。

## 安全与合规

- 不登录招聘网站，不绕过验证码、反爬机制或访问控制。
- 只处理已配置并允许访问的官方来源。
- 来源同步包含 robots.txt、SSRF、超时、内容大小和批量上限保护。
- JWT 密钥、数据库密码和其他敏感配置通过环境变量提供。
- GitHub 仓库启用 CodeQL、Dependabot、Secret Scanning 和 Push Protection。

## 验证结果

- 前端：Prettier、ESLint、TypeScript strict、Next.js production build 通过。
- 后端：Ruff、Ruff format、strict mypy、pytest 通过。
- 数据库：全新 PostgreSQL 数据卷从 `0001` 迁移至 `0004 (head)`。
- 端到端：Playwright 4/4 通过。
- GitHub Actions：frontend、backend、e2e、Python CodeQL 和 JavaScript/TypeScript CodeQL 通过。

## 本地启动

```powershell
git clone https://github.com/h46373824-tech/offerPilot-AI.git
cd offerPilot-AI
git checkout v1.0.1
Copy-Item .env.example .env
docker compose up --build -d
docker compose ps
```

- Web：http://127.0.0.1:3000
- API：http://127.0.0.1:8000
- OpenAPI：http://127.0.0.1:8000/docs

停止服务：

```powershell
docker compose down
```

## 已知限制

- 每日同步由本地容器内单实例调度器执行；电脑关机或容器停止期间不会运行。
- 官方网页结构、robots.txt 或条款变化可能导致来源暂停或需要适配。
- 自动发现的数据默认进入待核验状态；只有受信任适配器可以自动刷新核验状态。
- 正式数据具有核验时效，投递前必须再次访问官方页面确认。
- 本地附件存储适合个人部署；多用户生产环境仍需对象存储、恶意文件扫描和静态加密。

```powershell
git fetch --tags
git checkout v1.0.1
docker compose up --build -d
docker compose exec backend alembic upgrade head
```
